# metropolix-navigator

travelers guide for mapping the metropolis: a one-page reference for the **intellijel metropolix**, the multitrack pitch, gate and mod sequencer. the three rows of sliders and switches, the edit pattern, per-stage edits, track settings, the alt functions, run, reset and loopy, mod lanes, ctrl knobs, aux inputs, randomizing and specs.

sources: the intellijel metropolix manual (firmware 1.6.5); panel drawing after its front panel overview.

not affiliated with intellijel.
