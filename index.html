01

what it is

mx_01
one sequence
eight stages: a pitch slider, a pulse count switch and a gate type switch each
two tracks
trk 1 + trk 2 play those stages their own way: order, length, clock, gates
8 mod lanes
eight more 8-stage voltage lanes, sent to an out or inside
memory
64 presets (8 banks × 8) · live settings survive power off
02

the three rows

mx_02 · fig.01
pitch
the stage’s note, quantized to the scale + [ scale ]
pulse count
how many clock pulses the stage lasts · 1 – 8
gate type
hold = one long tied gate · multi = a gate per pulse · single = one gate · rest = none
not matching?
a pitch override, accum, aux or a loaded preset is winning · [ exit ] 1 s = sync to panel

the edit pattern

mx_03 · the big idea · fig.02
1
[ trk 1 ] or [ trk 2 ] · pick the track
2

04

per-stage edits

mx_04 · edit + …
[ slide ] [ skip ]
glide into the stage (red) · drop the stage and its pulses (orange)
[ pitch ] [ gate ]
a fixed note C0 – C5 (yellow) · gate rest, 1 – 99 % or 100 % hold (green)
[ ratch ] [ prob ]
1 – 8 repeats (cyan) · 0 – 100 % chance, per stage or per pulse (blue)
[ accum ]
adds scale degrees each stage, pulse or ratchet (magenta) · range on [ lim ]
[ cv ]
±5 V per stage · silent until an out is set to cv + [ a ] [ b ]
05

track settings

mx_05 · the bottom-left row
[ order ]
21 play orders (pendulum, hopscotch, pedal point, brownian, shuffle, random …) · push = reverse
[ len ]
stages 1 – 8 · [ alt ] + turn = offset · pulses 1 – 64 or auto
[ div ] [ swing ]
track clock divide · pulse count div · swing 50 – 78 %
[ slide ] [ gate ]
slide time + type (analog · tempo · acid) · gate length + gate scale
tip
give the two tracks different lengths or orders · instant counterpoint
__fig.01 : gate typespulse count 3 · gate length 50 %
06

alt functions

mx_06 · alt, then a stage button
[ load ] [ save ]
turn = bank (by colour) · stage button = slot · save can also clear
[ a ] [ b ]
what out A / B sends: cv lane, a mod lane, first/last pulse, new stage, root, run, ctrl
[ clk ] [ mx ]
clock out /1 – /256 + offset · gates for a gx or qx expander
[ lim ] [ type ]
accum limits, polarity, reset · cv lane = voltage or gate toggle
[ alt ] + [ trk ]
track menu: transpose ±60, slider octaves 1 – 4, invert, gate stretching
07

run · reset · loopy

mx_07 · transport
[ run ]
start / stop · setup sets run/stop or run/pause
[ reset ]
back to the start stage · hold [ trk 1 ] and press = that track only
[ ∞ ] + hold 1
loop from that stage for the loop pulses set on screen
[ ∞ ] + hold 2
loop between the two stages · press [ ∞ ] again to latch
stopped
the stage buttons play their notes like a keyboard
[ ∞ ] + [ trk ]
mute that track · or a stage button = mute that mod lane
08

mod · ctrl · aux

mx_08 · modulation
mod lanes[ mod ] › [ edit ] + stage 1 – 8
that lane opens · stage buttons + encoder set ±5 V, push = step or ramp · press mod = its destination + track
ctrl 1 · 2its black button
pick a parameter and track · the knob sets the value directly
aux x y zits button
±5 V in, attenuverter scales · offsets the value · on a gate target the knob alone flips it
randomizealt › x · y · z
on any edit screen: x = random · y = nudge · z = back to before
